# ixelai.com

The source of [ixelai.com](https://ixelai.com), the home of Ixel, Ixel MAT, Handoff and Machines.

It's plain static pages: no build step, no trackers, and nothing loaded from anyone else's servers. GitHub
Pages publishes `main`.

- **Using Ixel?** Start at [ixelai.com](https://ixelai.com): the [install guide](https://ixelai.com/docs/install/),
  the [docs](https://ixelai.com/docs/), and [what stays on your computer](https://ixelai.com/docs/privacy/).
- **Changing the site?** See [CONTRIBUTING.md](CONTRIBUTING.md).
- **Found a security problem?** Email **openixel.ai@proton.me**. See [SECURITY.md](SECURITY.md).
