About Ixel · Our mission

We help people get more from the AI they already use, by getting their models to check each other's work, share the load, and run on their own machines, under their control.

What we believe

Four ideas behind every tool.

  • Your machine, your keys.

    Our tools run on your computer and keep your API keys and logins there. Nothing waits on the network for someone else to connect.

    In practiceIxel MAT's browser app listens only on your computer. Handoff never opens a network port. Ixel Console connects only to the sessions you start.

  • Bring the AI you already have.

    Claude, ChatGPT, Gemini, Copilot, or a model running on your own computer. Our tools work with the subscriptions and keys you already pay for, and with free local models.

    In practiceIxel MAT puts them on one panel. Handoff pairs Claude with Codex. Ixel Console reaches OpenClaw, Hermes or any agent you run.

  • Check AI output before trusting it.

    An answer, a task note or a command from a model is information to weigh, never an instruction to follow.

    In practiceIxel MAT fences each answer before another model reads it. Handoff marks everything on the board as untrusted. Ixel Console runs only preset or checked commands.

  • Prove it, don't promise it.

    Every tool ships a written threat model and tests that attack its own protections.

    In practiceFake models try to make Ixel MAT's CLIs run commands. Handoff is tested against a planted board written to hijack an agent. Ixel Console's SSH checks are tested against the real ssh.

Where we are

Small, early, and building carefully.

Ixel is small and just getting started. Today that's three tools, all MIT-licensed and in private preview. We build for Windows first, with macOS and Linux supported too.

We'd rather ship a few tools that work well than many that don't, so each one gets a security review, tests that try to break it, and plain documentation before it's called done.

The mark

Three stars, three tools.

The Ixel mark is a crescent moon with three stars, and each star is one of our tools. Star charts name stars with Greek letters, brightest first, so Ixel MAT is α. There's room in the sky for more.
