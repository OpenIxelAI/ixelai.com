Install Ixel

One command installs Ixel MAT, Handoff and the Ixel app. It needs no administrator rights, and running it again updates everything it installed.

Before you start

You needNotes
Windows 10 or 11, macOS 12 or newer, or LinuxOn Linux it's been tried on Ubuntu, Debian, Fedora and Arch.
Python 3.10 or newerOn Windows, and on a Mac with Homebrew, the installer offers to install it. On Debian and Ubuntu you also need python3-venv.
GitOn Windows the installer offers to install it. On a Mac it comes with Apple's Command Line Tools, which the installer offers to open.
At least one AIAn API key, a subscription program such as Claude Code or Codex, or a local model in Ollama or LM Studio. You add them after installing, in setup.

You can read the installers before you run them: install.ps1 for Windows and install.sh for macOS and Linux.

Everything, or one tool

Most people want all of Ixel. If you only want one tool, each has its own line, and you can add the other later by running its line.

InstallsWindows (PowerShell)macOS and Linux
Ixel: Ixel MAT, Handoff and the appirm https://ixelai.com/install.ps1 | iexcurl -fsSL https://ixelai.com/install.sh | sh
Ixel MAT and the appirm https://ixelai.com/ixel-mat/install.ps1 | iexcurl -fsSL https://ixelai.com/ixel-mat/install.sh | sh
Handoffirm https://ixelai.com/handoff/install.ps1 | iexcurl -fsSL https://ixelai.com/handoff/install.sh | sh

Step by step

Windows

  1. Open PowerShell

    Press the Windows key, type PowerShell, and open Windows PowerShell. Open it the normal way, not with "Run as administrator": Ixel installs into your own user folder.

  2. Run the installer

    Paste this line and press Enter:

    irm https://ixelai.com/install.ps1 | iex

  3. Say yes to Git and Python, if it asks

    If Git is missing, it asks Git is needed to download Ixel. Install Git now with winget? [Y/n]. If Python is missing or older than 3.10, it asks Install Python 3.13 now with winget (Microsoft's installer)? [Y/n]. Press Enter for yes. winget is the installer that comes with Windows; it may show its own progress, and Windows may ask you to allow the change.

  4. Wait for "Ixel is installed"

    It downloads Ixel MAT and Handoff with Git, makes a private Python environment for each, and adds the ixel and handoff commands and an Ixel entry in the Start Menu. Then it says:

  5. Open a new window, and add your models

    Close PowerShell and open a new window, so it finds the new commands. Then run ixel setup: see Set up your models.

Smart App Control

Windows 11's Smart App Control blocks programs that aren't signed, and the ixel.exe that Python's installer writes isn't. So the installer makes ixel a small ixel.cmd that runs the environment's own python.exe, which is signed, and the Start Menu's Ixel starts the same way. Handoff does the same where Smart App Control is on.

macOS

  1. Open Terminal

    It's in Applications, in the Utilities folder, or press ⌘ Space and type Terminal.

  2. Run the installer

    curl -fsSL https://ixelai.com/install.sh | sh

  3. Install Apple's Command Line Tools, if it asks

    They bring Git and the compiler that builds Ixel's Mac app. If they're missing, the installer asks Open Apple's installer for them now? [Y/n]. Press Enter, finish Apple's installer in its own window, then run the same command again.

  4. Install Python, if it asks

    If you have no Python 3.10 or newer and you use Homebrew, it offers brew install python@3.13. Without Homebrew, get Python from python.org and run the command again.

  5. Open a new window, and add your models

    When it says Ixel is installed, open a new Terminal window and run ixel setup. Ixel is in the Applications folder inside your home folder (~/Applications), and Spotlight finds it.

The Mac app

The installer builds Ixel.app, a native window with its own Dock icon, using the Command Line Tools. If it can't, Ixel opens in Chrome's or Edge's app mode until you install them and run ixel update. If you already have an app called Ixel that isn't this one, Ixel's is called Ixel MAT instead, and the installer says so.

Linux

  1. Run the installer

    In a terminal:

    curl -fsSL https://ixelai.com/install.sh | sh

    It never uses sudo. If Git, Python or python3-venv is missing, it stops and prints the command that installs it for your system (sudo apt install python3-venv on Debian and Ubuntu, for example). Run that, then the same command again.

  2. Read what it did

  3. Get Ixel's own window (optional)

    Ixel opens in a native GTK window when your system's Python has GTK and WebKit. Without them it uses Chrome's or Chromium's app mode, or your browser. To get the window:

    sudo apt install python3-gi gir1.2-webkit2-4.1

    or on Fedora sudo dnf install python3-gobject webkit2gtk4.1.

  4. Open a new window, and add your models

    Open a new terminal window and run ixel setup. Ixel is in your app menu.

Another shell

The installer adds ~/.local/bin to your PATH for bash, zsh and fish. With another shell it prints the line to add instead. For sh, dash or ksh, put export PATH="$HOME/.local/bin:$PATH" in ~/.profile, then log out and back in.

What the installer changes

Everything goes in your own user folder:

WhatWindowsmacOS and Linux
Ixel MAT: its code and a private Python environment%LOCALAPPDATA%\IxelMAT~/.local/share/ixel-mat
Handoff: the same%LOCALAPPDATA%\Handoff~/.local/share/handoff
The ixel and handoff commands%USERPROFILE%\.local\bin, added to your user PATH~/.local/bin, added to your shell's startup file
The Ixel appStart Menu: IxelMac: ~/Applications/Ixel.app. Linux: your app menu

It never touches your system's Python, and never deletes work of yours: if a tool's folder holds changes you made, it stops and says so instead of replacing them.

Check that it worked

In a new terminal window:

ixel doctor

It checks each part of Ixel (your settings, each model, Handoff, Git, the window, and SSH once you have machines), and prints the one line that fixes each problem. ixel doctor --check also asks each model's server whether it answers. The app's Health page shows the same. For Handoff, run handoff doctor in a project folder.

Update

Run ixel update and handoff update, or run the install command again. The ixel chat in the terminal looks once a day and tells you when there's something new (it runs git fetch against GitHub). To turn that off, add this to Ixel's settings file, ~/.config/ixel-mat/config.toml:

[updates]
check = false

Uninstall

First take Handoff out of the apps it connected (Claude Code, Codex and the rest):

handoff setup --remove

Then remove the programs:

Windows

Remove-Item -Recurse -Force "$env:LOCALAPPDATA\IxelMAT", "$HOME\.local\bin\ixel.cmd", "$([Environment]::GetFolderPath('Programs'))\Ixel.lnk"
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\Handoff", "$HOME\.local\bin\handoff.exe"

Where Smart App Control is on, Handoff's command is handoff.cmd instead of handoff.exe.

macOS

rm -rf ~/.local/share/ixel-mat ~/.local/bin/ixel ~/Applications/Ixel.app
rm -rf ~/.local/share/handoff ~/.local/bin/handoff

Linux

rm -rf ~/.local/share/ixel-mat ~/.local/bin/ixel "${XDG_DATA_HOME:-$HOME/.local/share}/applications/ixel.desktop"
rm -rf ~/.local/share/handoff ~/.local/bin/handoff

If the installer named Ixel's app Ixel MAT (because you had another app called Ixel), use that name: Ixel MAT.lnk, Ixel MAT.app or ixel-mat.desktop. Your settings, keys and history stay until you delete them; Privacy lists every file and where it is.

Troubleshooting

"ixel" isn't found

Open a new terminal window: the one you installed from doesn't know about the new commands yet. If a new window doesn't find it either, your shell isn't one the installer knows; add ~/.local/bin to your PATH as the installer said.

"Install stopped"

The lines above it say why, and what to install or change. Fix that and run the same command again. Running it more than once is safe: it updates what's there.

Git asks for a username and password

The installer downloads Ixel MAT and Handoff from their repositories on GitHub. While a repository isn't public yet, Git asks for a GitHub login that has access to it. Git doesn't take your GitHub password there: run gh auth login first with the GitHub CLI, or paste a personal access token when it asks for a password.

It says I need to be an administrator

Ixel itself doesn't. Installing Git or Python with winget may ask Windows for permission; that's winget, and you can say no and install them yourself instead.
