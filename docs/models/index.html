Which model for each job

A review has four jobs, and they don't need the same model. Put your strongest model where it counts, and let cheaper ones do the rest.

Picks from Artificial Analysis, read 4 October 2026

The four jobs

JobWhat it doesWhat matters
Writes the verdictReads every answer and every review, and writes the final answer.Being right. It's the answer you read.
Big model that verifiesIn Saver, reads the drafts and the reviews and says, in a few words, which draft is right or what's wrong.Being right. It reads a lot but writes little, so it costs less than you'd think.
Models that draftIn Saver, answer the question and review each other.Good enough, cheap, and from different makers, so they don't all make the same mistake.
Decides, in TriageAnswers short questions between rounds: how much checking does this need, do these answers agree?Fast and cheap, and good enough to judge.

Outside Saver, every model on your panel answers and reviews; the picks for drafting are good panel members too.

Through Claude Code, Codex or Gemini CLI, a model's calls count against your plan rather than costing per token, so the cost column doesn't apply. The score still does.

How the picks are made

A script on this site reads the benchmark's numbers and applies the same rules every time, so the picks change only when the numbers do:

  • Writes the verdict, and verifies: the highest score among models with a known cost. When the same model at a lower thinking setting scores within 5 points for a third of the cost or less, the table says so.
  • Models that draft: the best score among models that cost a tenth of the top pick's or less, one per maker.
  • Decides, in Triage: the cheapest models that score at least half the top score, one per maker.
  • Thinking settings Ixel can use: through the API Ixel uses for every maker but Anthropic, xhigh and max are sent as high. So those settings only count for Claude models.

Score is Artificial Analysis's Intelligence Index, which combines its tests of reasoning, knowledge, math and coding into one number. Cost is cost per task: Artificial Analysis's average cost to run one task of its tests at that setting, in US dollars. Use it to compare models, not as a bill. The picks come from its public leaderboard and open-weights pages, read on 2026-10-04.

A benchmark is one view. Your own questions may favor a different model, and Ixel shows you how each model did in every review, so trust what you see there too.

Set each job

In the app, open Settings. Or set them in your settings file (~/.config/ixel-mat/config.toml), by the name each model has on your panel:

JobIn SettingsIn the file
Writes the verdictAsking, Who writes the verdict[review] moderator
Big model that verifiesSaver, Big model that verifies[saver] verifier
Models that draftSaver, Models that draft[saver] drafters
Decides, in TriageTriage, The model that decides[triage] agent
 
[review]
moderator = "opus"            # writes the verdict (left out: the author of the best-rated answer)

[saver]
verifier = "opus"             # your big model
drafters = ["gpt", "gemini", "qwen"]   # left out: every model but the verifier
verifier_effort = "low"       # checking is easier than writing

[triage]
enabled = true
agent = "luna"                # a fast, cheap model of yours

The names (opus, gpt, luna) are what you called each model in ixel setup. Each one's model and thinking setting are picked in Settings, Models, or with ixel model; Set up your models says how.

Where the numbers come from

The scores and costs are from Artificial Analysis, an independent company that tests AI models and keeps its results up to date as new ones come out. Ixel isn't connected with them. This page is refreshed from their numbers, and the date at the top says when. Your Ixel app doesn't contact them; only the script that updates this page does.
