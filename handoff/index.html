Handoff

Let Claude and Codex work as partners on the same project.

Say “Codex, take the tests; Claude, do the API” in either app. Tasks, notes and reviews pass between them through a shared task board on your computer, so you stop being the copy-paste courier. Handoff works in Claude Desktop, Claude Code and Codex, and you can see everything from your terminal.

Who it's for

Made for people who…

  • Use both Claude and Codex

    Give each one the part it does best, and let them pass the work back and forth.

  • Are tired of copying between chats

    Notes, acceptance checks and reviews travel on the board instead of through your clipboard.

  • Want a record of who did what

    Every note, handoff and review is kept in order with its time, and agents can't edit or delete it.

  • Care about reviews

    Nobody reviews their own work, and a task needs a review or a reason to be done. Your Ixel MAT panel can give a second opinion too.

How it works

One ritual: “check your handoffs.”

  1. Split the work

    In Claude, say Hand the tests to Codex, and you do the endpoint. Claude creates a task for each, with notes and acceptance checks.

  2. Check your handoffs

    Switch to Codex and say Check your handoffs. Codex picks up its task and does the work.

  3. Hand it back

    Codex hands the task back with what it did, what's left, how to check it, and the files it touched.

  4. Review and finish

    Claude reads the handoff, finishes up, and asks Codex or your Ixel panel to review before the task is done.

Nothing wakes the other app up: an assistant only acts when you prompt it. So after one agent hands work over, you switch apps and say “check your handoffs.” That's the whole ritual.

What it does

What you get.

A plugin in each app
Claude Desktop, Claude Code and Codex each get Handoff's tools: an inbox, the board, and tools to create, claim, hand off and review tasks.
Your board in the terminal
handoff board shows who's doing what and what's blocked. handoff show T-12 prints a task's whole history.
Rules the board enforces
Only the assignee can hand a task on, nobody reviews their own work, and agents can't delete tasks or rewrite history.
Warnings before edits collide
When two active tasks claim overlapping files, both agents are warned: the second as it claims them, the first in its inbox and on its next note.
Reviews by your Ixel panel
With Ixel MAT installed, a review can also ask your panel of models for a verdict.
The worker (preview)
Approve one task and let Claude Code work on it in its own git worktree while you're away. It commits on a branch and never pushes. On Windows it edits files only, for now.
Built to be safe
  • Handoff never opens a network port. Each app talks to it over stdio.
  • Everything on the board is marked untrusted, so one agent's text can't take over another.
  • Text that looks like an API key, token or private key is refused, not stored.
  • The worker runs only tasks you approved on this computer, stays in its worktree, and never pushes.
Install

Get Handoff running.

You need:

  • Windows 10 or 11, macOS 12 or newer, or Linux
  • Python 3.10 or newer (on Windows, and on a Mac with Homebrew, the installer offers to get it)
  • Git (on Windows the installer offers to get it; on a Mac it comes with Apple's Command Line Tools)
  • Claude (Desktop or Claude Code) and Codex

This installs Handoff on its own. It downloads Handoff from GitHub, needs no administrator rights, and updates it when you run it again. You can read it first: install.ps1, install.sh.

Windows: in a normal PowerShell window (not "Run as administrator"), run:

irm https://ixelai.com/handoff/install.ps1 | iex

macOS or Linux: in a terminal, run:

curl -fsSL https://ixelai.com/handoff/install.sh | sh

Then open a new window, go to your project's folder, run handoff setup --write, and restart Claude and Codex.
