α Multi-agent terminal

Ixel MAT

Ask several AI models at once. They answer, grade each other's work without knowing whose it is, and agree on a verdict.

  • Answers are labeled A, B, C in a random order, and each reviewer sees them in a different order. A model's grade of its own answer doesn't count. You see who was flagged, and who conceded.
  • Usage saver mode lets cheaper and local models draft and review, while your best model only checks the result.
  • Uses the keys and subscriptions you already have: Claude Code, Codex, Gemini CLI, GitHub Copilot, OpenCode, Grok Build, and local models through Ollama or LM Studio.

Handoff

Let Claude and Codex work as partners on the same project. Say "Codex, take the tests; Claude, do the API," and the work passes between them. You stop being the copy-paste courier.

  • A plugin for Claude Desktop, Claude Code and Codex. Agents create tasks, hand them over with notes and acceptance checks, and ask each other for reviews.
  • The board enforces its own rules: only the assignee can hand a task on, nobody reviews their own work, and agents' Handoff tools can't change the history.
  • You stay in charge from the terminal. handoff board shows who's doing what and what's blocked, and handoff show T-2 shows everything that happened to a task.

Machines

Your servers, from a $5 VPS to your home lab, and the agents on them. Connect in one click, or run one command on all of them at once.

  • Works with OpenClaw, Hermes, a shell, or a command you type. Each machine keeps its own.
  • Import the hosts in your ~/.ssh/config, or Ixel Console's machines with the keys it pinned. Connect opens a terminal; Run on machines shows how each one ended and its output.
  • Each server's key is pinned the first time, and ssh itself refuses one whose key changed. It runs only what you type or pick, and logs it on your computer.

Install

Get Ixel: Ixel MAT, Handoff and the Ixel app in one command.

You need:

  • Windows 10 or 11, macOS 12 or newer, or Linux
  • Python 3.10 or newer (on Windows, and on a Mac with Homebrew, the installer offers to get it). On Debian and Ubuntu, also python3-venv
  • Git (on Windows the installer offers to get it; on a Mac it comes with Apple's Command Line Tools)
  • At least one AI: an API key, a subscription CLI such as Claude Code or Codex, or a local model

It downloads the tools from GitHub, and updates them when you run it again. The installer itself needs no administrator rights (getting Git or Python may). It never deletes changes of yours in a tool's folder: where it would have to, it stops and says so. You can read the installers first: Ixel's install.ps1 and install.sh, Ixel MAT's install.ps1 and install.sh, and Handoff's install.ps1 and install.sh.

Windows: in a normal PowerShell window (not "Run as administrator"), run:

irm https://ixelai.com/install.ps1 | iex

macOS or Linux: in a terminal, run:

curl -fsSL https://ixelai.com/install.sh | sh

Then, in a new terminal window, run ixel setup to choose your models. To connect Claude and Codex, go to your project's folder (it needs to be a git repository), run handoff setup --write, and restart the apps. With a shell other than bash, zsh or fish, the installer first prints the line to add to your PATH. Ixel opens from the Start Menu, Applications (in your home folder), or your app menu. The install guide goes through each step, with pictures.

How we build

Built the same careful way, all three.

Each tool ships a written threat model (its SECURITY.md) and tests that attack its own protections. Here is what that means for each one.

αIxel MAT βHandoff γMachines
Stays on your machine The browser app listens on 127.0.0.1 only and needs a key from the link it opens. Never opens a network port. Apps talk to it over stdio. No telemetry. It connects only to the machines you connect to or run on.
Keeps secrets out of reach API keys live in a file only you can read, and go only to the providers you set up. Common kinds of API keys and tokens, and private keys, are refused, not stored. Passwords aren't caught. It stores no passwords: your own ssh keys or ssh-agent sign in, and a password is typed in the terminal.
Limits what can run Subscription CLIs run answer-only: no shell, no file writes, in an empty folder. Runs an agent only for a task you approve. Edits happen in their own git worktree and are never pushed; answers, reviews and pictures go through Ixel MAT and change nothing in the project. Only what you type or pick runs. No model can reach your machines, and an address or user name can't pass for an ssh option.
Attacked in its own tests A test points each installed CLI at a fake model that tells it to run a command and read the key file, and fails if anything happens. It's run by hand, on Linux or macOS. Tests include a crafted board built to hijack an agent, and an attack on the worker. Tested against a real SSH server: a swapped host key is refused by ssh itself, and option-like addresses never get through.
