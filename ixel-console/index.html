Ixel Console

The SSH launcher built for the age of AI agents.

Connect to, manage and monitor the AI agents running on your machines, from a $5 VPS to your home lab. Save each machine as a profile, pick its agent (OpenClaw, Hermes or your own command), and connect in one click, with security checks built in.

Who it's for

Made for people who…

  • Run OpenClaw or Hermes

    Each agent's own commands are one click away: Status, Sessions, Logs and its TUI.

  • Have a home lab or a few VPSs

    Save every machine as a profile, or import them from your SSH config, and open a session in one click.

  • Run several agents at once

    Keep them in tabs, and broadcast one command to every agent of the same kind.

  • Take security seriously

    Host keys are pinned with no override, credentials live in Windows Credential Manager, and every connection attempt is logged.

How it works

From a saved profile to a live session.

  1. Add a machine

    Save a host as a profile, or import your hosts from ~/.ssh/config.

  2. Pick its agent

    OpenClaw, Hermes, or a custom command. Each host keeps its own.

  3. Connect

    The first time, you confirm the server's fingerprint and Ixel Console pins it. From then on, a changed key is blocked.

  4. Work

    Use the one-click macros, open more tabs, or broadcast a command to every matching agent.

What it does

What you get.

Agent presets
OpenClaw and Hermes each get four built-in commands. A custom agent runs what you type, checked for shell tricks.
Tabs and broadcast
Several sessions in one window, and one command sent to every agent of the same kind.
Host key pinning
Fingerprints are checked on every connection, and a mismatch blocks it. There's no “trust anyway” button.
Your system keychain
Passwords and tokens go in Windows Credential Manager (Keychain on macOS, Secret Service on Linux), never in a file.
SSH keys, made easy
Generate an ed25519 or RSA key, then Copy Key to Server adds it to the server for you, even on Windows.
An audit log
Every connection attempt is logged on your machine, with a short code you can search for.
Built to be safe
  • Preset agents can only run their four built-in commands.
  • Profiles hold no secrets. Credentials stay in your OS keychain.
  • Any check that fails refuses to connect.
  • No telemetry. The only network connections are the sessions you start.
Install on Windows

Get Ixel Console running.

You need:

  • Windows 10 or 11 (the OpenSSH client it uses is built in)
  • Python 3.10 or newer from python.org, with “tcl/tk and IDLE” left selected
  • Git (winget install Git.Git)

Ixel Console is in private preview. Its repository is private, so git clone asks for your GitHub login, and your account needs access. The macOS and Linux steps are in its README.

Open a normal PowerShell window (not "Run as administrator") and run:

cd ~
git clone https://github.com/OpenIxelAI/Ixel-Console.git
cd Ixel-Console
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1

Then open Ixel Console from the Start Menu, or run ixel-console in a new terminal.
