Machines

Your servers, and the agents on them, one click away.

Save your machines, from a $5 VPS to the Mac mini in the closet, pick what runs on each (OpenClaw, Hermes, a shell or your own command), and connect in one click. Or run one command on all of them at once. Each server's key is pinned the first time, and ssh itself refuses a server whose key has changed.

Who it's for

Made for people who…

  • Run OpenClaw or Hermes

    Each machine opens straight into the agent's TUI, status, sessions or logs, whichever you pick.

  • Have a home lab or a few VPSs

    Save every machine, or import them from your SSH config, open a session in one click, and check on all of them with one command.

  • Want SSH keys without the fuss

    Make a key in the app, and Copy my key to it adds it to the server for you, even on Windows.

  • Take security seriously

    Host keys are pinned and enforced by ssh itself, nothing a model writes can reach your machines, and every connection and run is logged on your computer.

How it works

From a saved machine to a live session.

  1. Add a machine

    Type its address, or import your hosts from ~/.ssh/config (or from Ixel Console).

  2. Pick what runs

    OpenClaw, Hermes, a shell, or a command you type. Each machine keeps its own.

  3. Check its key

    The first time, you see the server's fingerprint and say yes, and it's pinned. From then on, ssh refuses a changed key.

  4. Connect, or run

    Connect opens a terminal running that machine's command. Run on machines runs one command on the ones you pick and shows each one's output.

What it does

What you get.

Agent presets
OpenClaw and Hermes each get four built-in commands: the TUI, status, sessions and logs. Or a shell, or a command you type.
Import what you have
Bring in the hosts in ~/.ssh/config (ssh keeps using their settings, jump hosts included), or Ixel Console's machines with the keys it pinned.
Host key pinning
A key is pinned only after you've seen its fingerprint (or said yes to it in Ixel Console), and ssh is told to accept that key and no other. Checking it sends nothing of yours along. A changed key stops everything until you forget the old one on purpose.
Run on machines
One command on the machines you pick, up to 8 at once, each with a time limit. Nothing is asked along the way, so each machine signs in with a key or ssh-agent, and its key must be pinned first. You see how each one ended and its output (the first 64 KB).
SSH keys, made easy
Make an ed25519 key, then Copy my key to it adds it to the server's authorized_keys, once, even on Windows.
A log on your computer
Every connection, run, import, new key and key pinned or forgotten is logged on your computer, and nowhere else.
Built to be safe
  • It runs only what you type or pick. No model can reach your machines.
  • A machine's address can't be read by ssh as an option, and every program gets what it runs one argument at a time.
  • It uses the ssh you already have, with your keys or ssh-agent. Ixel stores no passwords.
  • No telemetry. The only connections are the ones you start.
Install

Machines comes with the Ixel app.

Install Ixel (or Ixel MAT on its own: the app comes with it), open the app, and pick Machines on the left. In a terminal, ixel machines lists them and ixel machines connect NAME connects.

You need the OpenSSH client: it comes with Windows 10 and 11 and with macOS, and on Linux it's the openssh-client (or openssh) package. On Linux, Connect opens Konsole, GNOME Terminal, kitty, Alacritty or xterm; with none of them, it gives you the line to run in your own terminal.

Coming from Ixel Console? In Machines, press Import and pick Ixel Console: your SSH machines come over with the keys it pinned. Then remove Ixel Console with ixel-console uninstall.

Windows: in a normal PowerShell window (not "Run as administrator"), run:

irm https://ixelai.com/install.ps1 | iex

macOS or Linux: in a terminal, run:

curl -fsSL https://ixelai.com/install.sh | sh

Ixel opens from the Start Menu, Applications (in your home folder), or your app menu.
