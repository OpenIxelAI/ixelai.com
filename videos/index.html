Ixel MAT

Ask the panel

Is the regex ^(a+)+$ safe to run on user input? Claude (Sonnet) and Grok Build answer on their subscriptions, and Qwen3 4B answers on the computer itself. They grade each other's answers without knowing whose they are, and Claude writes the verdict. The small local model calls the regex safe, the other two flag it, and the verdict explains why it isn't. Ask, in the app docs.

Handoff

Run a task on the Board

A task goes to Qwen3 4B, a free model running on the computer through Ollama. It works on its own branch in a copy of the project and hands the task back with what it did and what it used: 4.1k tokens read, 405 written, $0. Merge adds the work to your branch. Nothing is pushed. How the worker runs a task.

Agent (beta)

Give the Agent a goal

The Agent, here on Grok Build, reads the code, shows the change to cart.py before it edits it, and asks before each command. Commands run in a sandbox that has no network and can write only in the project's folder and the temp folder, so when pytest can't be installed, it runs the tests with Python instead. Both tests pass after 8 model calls (about $0.04 at API prices). The Agent, in the app docs.

Machines

Your servers in one place

Machines lists the SSH servers you added, grouped as you like. Edit one, check its key, or run one command on several at once. Machines, in the app docs.
